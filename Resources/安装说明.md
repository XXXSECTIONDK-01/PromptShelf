# 词屿 0.1.12

将 PromptShelf 拖入 Applications，退出旧版后打开新版本。

## 本次更新

- 使用新的默认应用图标，关于页与 Dock、Finder 保持一致。
- 自定义品牌动画按窗口所在显示器的刷新节奏更新，兼容高刷新率屏幕；静止或隐藏时停止动画回调。实际帧率由 macOS 根据显示模式、电量与系统负载调度。
- 关于页新增 MADE BY ANDY CHEN 创作者署名与 GitHub 链接。
- 保留当前排版、颜色、功能及资料库。

## 0.1.11 侧栏图标颜色

- 左侧分类图标使用分类已保存的颜色，与列表中的分类色一致。
- 应用功能图标恢复各自默认颜色，不再统一使用应用强调色。
- 保留暖色批注、宋体标题、品牌滚动彩蛋及现有布局。

## 0.1.10 暖色批注与宋体标题

- 采用暖色批注排版：暖棕色分区小字、细下划线和轻量批注，标题统一使用宋体。
- 左上角 PromptShelf 支持悬停上下滚动切换为「词屿」。连续移入第 11 次触发彩蛋，稍后自动收起。
- 保留现有浮岛、蓝色选中态、分类色、细滚动条与缩放偏好；正文、附件和同步记录不变。

## 0.1.9 颜色与滚动条

- 提示词列表中的分类图标与名称恢复该分类原有颜色；蓝底选中时使用同色系浅色。
- 应用内滚动条改为细覆盖式样式，保留原生滚动、拖动和自动隐藏。
- 保留现有布局、字体、120% 默认缩放及用户设置。20 套候选排版在独立 HTML 中提供，待选定后应用。

## 0.1.8 界面缩放

- 应用内文字、图标、控件和间距默认放大至 120%。
- 在「外观 → 界面缩放」选择 80%–150%，实时生效并自动保存；可一键恢复 120%。
- 主窗口、编辑窗口与快捷面板统一缩放，窗口尺寸按可用屏幕空间适配。
- 保留现有浮岛、渐变、蓝色选中态及全部功能。

## 0.1.7 外观改进

- 左侧功能区使用浮岛卡片，淡蓝渐变跟随提示词选中行的位置变化。
- 提示词选中态使用蓝底白字。
- 参照提供版本调整主界面的字号与文字间距。

## 0.1.6 的性能与存储改进

- 采用 01 号原生分栏设计：浅灰侧栏、白色正文、蓝色线性图标、灰色选中状态。收紧导航与列表间距，强化标题层级。
- Markdown 批量导入、全文搜索与磁盘保存由后台执行。长正文使用原生文本视图，按可见区域排版。
- 单个 Markdown 最大 20 MB，单次最多 200 个文件、合计 256 MB。本地资料库总量最大 512 MB。
- 兼容旧版 schemaVersion/settings 资料库，升级时保留提示词、分类、使用记录和可识别的偏好设置。迁移前原文件存放于 Migrations。

## 本地资料库

所有正式内容集中保存于：

`~/Library/Application Support/PromptShelf/`

- `library.json`：内容索引与设置。
- `Documents/`：UTF-8 正文与 Markdown 文件副本。
- `library.backup.json`：上一份有效索引；对应文件版本会保留。
- `Migrations/`：升级前的原始资料库。
- `Recovery/`：从备份恢复前保留的异常索引（如有）。

不要仅复制 library.json 迁移资料库。请在「数据与备份」导出完整 JSON 备份，或复制整个 PromptShelf 目录。旧版应用无法读取新的本地索引结构；需要回退时使用升级前备份。

读写失败会显示错误并保留原文件。无法读取资料库时暂停写入，不使用示例内容替换列表。保存失败时可在「数据与备份」重试保存或导出内存中的内容。

## 快捷调用

默认 Control + Option + P 唤起词屿，可在「快捷键与填入」自行录制组合键。点击条目填入正文；右键「即时编辑…」可临时修改一次，再填入原输入框。右键「以 Markdown 文件输出」可输出关联附件，纯文本条目会生成临时 MD 文件。目标应用须支持文件粘贴或拖放。

拖入 Markdown 会保存文件副本，源文件之后被移动或删除不影响词屿。备忘录导入的附件独立保存，编辑正文不改写附件。

## 备忘录

在「备忘录同步」中连接系统备忘录，选择账户与文件夹导入，或将提示词与 Markdown 附件导出到「词屿」文件夹。iCloud 跨设备同步由系统备忘录完成。

最低 macOS 14，适用于 Apple Silicon。本安装包使用本地开发签名。辅助功能与自动化权限由用户首次使用时在系统中设置。
